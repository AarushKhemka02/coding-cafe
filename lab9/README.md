# Lab 9 — NumPy, Pandas, and Matplotlib

This lab uses scientific Python libraries to analyse plant-growth, temperature, and student-performance data.

## Contents

- `lab-09.ipynb` — completed notebook covering NumPy arrays, Pandas DataFrames, filtering, grouping, summary statistics, and Matplotlib charts.

## Run the notebook

Open `lab-09.ipynb` in Jupyter Notebook, JupyterLab, VS Code, or Google Colab, then run the cells from top to bottom. The core lab requires NumPy, Pandas, and Matplotlib. The final optional NASA image cell also requires Requests and an internet connection.
